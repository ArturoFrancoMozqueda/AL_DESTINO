# AL DESTINO · repositorio de Arturo y Liz

**Estado: BORRADOR · design system v0.5.** Los originales, las propuestas y los entregables se guardan por separado. Ningún archivo nuevo implica una aprobación ni una publicación.

Empieza por el [design system HTML](marca/design-system.html), el [catálogo de PNG](marca/exportaciones/v05-png/index.html) o el [contexto vigente](contexto/vision-y-preferencias.md). Para trabajar con IA, lee primero [AGENTS.md](AGENTS.md).

| Carpeta | Qué corresponde aquí |
|---|---|
| `contexto/` | Visión, preferencias, límites, perfil, decisiones y registro de organización |
| `marca/` | Identidad vigente y sus fuentes; ver [mapa de marca](marca/LEEME.md) |
| `marca/assets/fuentes/` | Tipografías y licencias |
| `marca/assets/logos/` | Logo original de trabajo y piezas PNG extraídas para motion |
| `marca/tokens/` | JSON y CSS coherentes con el manual y el HTML |
| `marca/exportaciones/v05-png/` | PNG listos para consultar/usar, separados por categoría y con catálogo |
| `marca/motion/logo-al-destino/` | Composición HyperFrames editable, assets, pruebas y renders PNG |
| `marca/previews/` | Capturas de control visual del design system vigente |
| `marca/originales/` | ZIP y documentos heredados, intactos |
| `marca/archivo/` | Versiones anteriores y material descartado, fuera del flujo vigente |
| `investigacion/` | Fuentes y metodología de investigación |
| `planificacion/` | Oportunidades y plantillas de ideas; sin calendario aprobado |
| `produccion/` | Flujo y plantillas para preparar, editar y publicar episodios |
| `resultados/` | Métricas propias y esfuerzo de producción |
| `.agents/skills/` | Tres skills de investigación bajo demanda |
| `scripts/` | Exportación, extracción de piezas y validación |
| `validacion/` | Evidencia de las comprobaciones y sus límites |

Para una revisión visual, usa el HTML vigente y sus tokens. Los ejemplos tipográficos son propuestas; las aplicaciones fotográficas históricas contienen mockups identificados. Para investigación local, Airbnb y hoteles de playa, usa la skill correspondiente y fuentes actuales. Una oportunidad no autoriza publicar, reservar, comprar ni programar.

Comprobación del repo: `python3 scripts/validar.py`. Exportación y render: [instrucciones de herramientas](scripts/LEEME.md). El HTML y el catálogo de PNG se abren localmente sin servidor.
