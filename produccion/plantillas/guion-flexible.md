# Guion flexible · BORRADOR

ID / experiencia / promesa:

| Momento | Qué ocurre / pregunta | Qué capturar | Información verificada | Alternativa si no ocurre |
|---|---|---|---|---|
| Apertura | Una pregunta o momento real | Acción + reacción natural | | |
| Contexto | Por qué vinimos | Lugar + conversación | | |
| Experiencia | Descubrimos/probamos | Secuencias, detalles, audio | | |
| Aprendizaje | Qué nos sorprendió | Opinión desde lo vivido | | |
| Cierre | Para quién lo recomendaríamos | Reflexión de ambos | | |

Preguntas sugeridas, no diálogos para fingir:
- ¿Qué esperábamos y qué encontramos?
- ¿Qué repetiríamos o haríamos distinto?
- ¿Qué nos hubiera servido saber antes?

No inventar conflicto, reacciones ni un veredicto antes de vivir la experiencia. Si se incluye un costo, indicar fecha y qué comprende.
